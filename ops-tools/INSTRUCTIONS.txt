Quick Reference
===============================

INSTALLATION (run once per host)
--------------------------------
Linux/Cygwin:
  sudo ./install.sh [--ssh-port 12322] [--minimal] [--dry-run]

Windows (PowerShell as Admin):
  powershell -ExecutionPolicy Bypass -File Bootstrap-GameServerHost.ps1

BACKUPS (run via cron on each game server)
------------------------------------------
./backup.sh [--backup-root /sdb1/backups] [--keep-days 7]

Cron example (hourly):
  0 * * * * /home/gameserver/tools/scripts/backup.sh >> /var/log/backup.log 2>&1

STATUS MONITORING
-----------------
Display local status:
  ./status.sh [--json]

Report to MySQL (run every 5 minutes via cron):
  */5 * * * * /home/gameserver/tools/scripts/status.sh --report

Display fleet-wide status (run on core):
  ./status_all.sh [--json] [--summary] [--offline-only]

PASSWORD ROTATION (run on core only)
------------------------------------
./change_passwd.sh "NewPassword!" [--core-only] [--mysql-only] [--dry-run]

After running:
  1. Update content/staff-credentials.json
  2. Run: ./dr_rsync_push.sh core-dr.iaregamer.com
  3. Commit and push changes

FILE TRANSFER
-------------
./xfer.sh /path/to/folder hostname [--port 12322] [--delete] [--background]
./xfer.sh --check  # Monitor background transfer

DISASTER RECOVERY
-----------------
./dr_rsync_push.sh core-dr.iaregamer.com [SSH_PORT]

Syncs:
  - /home/gameserver/tools
  - /var/www/html/panel
  - /var/www/html/adminer
  - /var/www/files/backup
  - /var/www/files/installers
  - /etc (excluding host-specific files)
  - MySQL databases and grants

===============================
Configuration Files
===============================

servers.txt format:
  # Comments start with #
  core.iaregamer.com:12322
  core-dr.iaregamer.com:12322
  kc.iaregamer.com:12322

.password:
  Single line with the shared password (no trailing newline)
  chmod 600 /home/gameserver/tools/.password

Staff Credentials:
  Edit content/staff-credentials.json and commit changes.
  The staff-info.php page reads from this file.

===============================
MySQL Database: peer_status
===============================

Tables:
  nodes   - hostname, ip, first_seen, last_seen
  metrics - hostname, ts, cpu_used_pct, mem_used/total, disk_used/total, top_procs

Users:
  localuser@localhost     - Full access on local MySQL
  remoteuser@<server_ip>  - INSERT/UPDATE on peer_status from remote hosts

Created automatically by:
  - status.sh --report (creates tables on first run)
  - setup_mysql_users.sh (creates users/grants)

===============================
Troubleshooting
===============================

"MySQL client not found":
  Run: sudo apt install mysql-client (Debian/Ubuntu)
  Or:  sudo dnf install mysql (RHEL/CentOS)

"Password file missing":
  Create: echo 'YourPassword' > /home/gameserver/tools/.password
  Then:   chmod 600 /home/gameserver/tools/.password

"Permission denied (SSH)":
  Ensure sshpass is installed: sudo apt install sshpass
  Or configure SSH key authentication

"Cannot resolve hostname":
  Check servers.txt format and DNS resolution
  Test: getent hosts hostname.example.com
