# Quick Reference

Commonly used shortcuts and commands for our tools.

---

## VS Code

| Action | Shortcut |
|--------|----------|
| Command menu | `Ctrl + Shift + P` |
| Find file | `Ctrl + P` |
| Open terminal | `Ctrl + ~` |
| Split view | `Ctrl + \` |

---

## Unity

| Action | Shortcut |
|--------|----------|
| Play/Stop game | `Ctrl + P` |
| Save scene | `Ctrl + S` |
| Build settings | `Ctrl + Shift + B` |

---

## Unreal Engine

| Action | Shortcut |
|--------|----------|
| Play game | `Alt + P` |
| Save all | `Ctrl + S` |

---

## Git Commands

```bash
git clone <url>          # Download a repository
git pull                  # Get latest changes
git add .                 # Stage all changes
git commit -m "message"   # Save changes locally
git push                  # Upload changes
git branch               # List branches
git checkout -b newbranch # Create new branch
```
