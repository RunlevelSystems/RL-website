## 🛠️ Development Tools

### 1. **Visual Studio Code (VS Code)**
- **Common Shortcuts:**
  - Open Command Palette: `Ctrl + Shift + P` (Windows/Linux) / `Cmd + Shift + P` (Mac)
  - Search files: `Ctrl + P` (Windows/Linux) / `Cmd + P` (Mac)
  - Split Editor: `Ctrl + \` (Windows/Linux) / `Cmd + \` (Mac)
  - Toggle Terminal: `Ctrl + ~` (Windows/Linux) / `Cmd + ~` (Mac)
- **Commonly Used Extensions:**
  - GitHub Copilot: [Get it here](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot)
  - Prettier (Code Formatter)
  - ESLint (Linting)
- **Quick Setup Guide:** [VS Code Guide](https://code.visualstudio.com/docs)

## 🌍 Website Development (XAMPP)
- **Start Server:**
  - Open XAMPP Control Panel and start Apache and MySQL services.
- **Default Paths:**
  - Localhost: `http://localhost`
  - Project Files: Place files in the `htdocs` folder (e.g., `C:/xampp/htdocs`).
- **Quick Tips:**
  - Restart Apache if configuration changes are not taking effect.
  - Use `phpMyAdmin` for database management: `http://localhost/phpmyadmin`
- **Quick Setup Guide:** [XAMPP Guide](https://www.apachefriends.org/faq.html)

## 📡 SSH and SFTP (Bitvise SSH Client)
- **Quick Commands:**
  - Connect to a Server: Enter Hostname, Port, and Credentials, then click "Log in."
  - Upload Files: Drag and drop files into the SFTP panel.
- **Common Issues:**
  - Ensure the server is running before attempting to connect.
  - Check for firewall or port forwarding issues if unable to connect.

## 🚀 GitHub

### 1. **GitHub Desktop**
- **Common Workflows:**
  - Clone a Repository: `File > Clone Repository`
  - Commit Changes: Make changes > Write a commit message > Click "Commit to Main."
  - Push Changes: Click "Push origin" to upload changes to GitHub.
- **Quick Setup Guide:** [GitHub Desktop Docs](https://docs.github.com/en/desktop)

### 2. **Git Commands**
- **Common Git Commands:**
  - Clone a Repository: `git clone <repo-url>`
  - Check Branches: `git branch`
  - Create a New Branch: `git checkout -b <branch-name>`
  - Commit Changes: `git commit -m "Your commit message"`
  - Push Changes: `git push origin <branch-name>`
- **Quick Setup Guide:** [GitHub CLI Docs](https://cli.github.com/)
