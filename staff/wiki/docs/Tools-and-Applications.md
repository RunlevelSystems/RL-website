# Tools and Applications

This page provides an overview of the tools and applications used by the team, along with download links and guides to help you get started with them.

---

## 🛠️ Development Tools

### 1. **Visual Studio Code (VS Code)**
- **Purpose:** Code editor for GitHub access and development.
- **Download Link:** [Download VS Code](https://code.visualstudio.com/)
- **How-to Guide:** [Getting Started with VS Code](https://code.visualstudio.com/docs)

### 2. **Unity**
- **Purpose:** Game development platform for creating 2D and 3D games.
- **Download Link:** [Download Unity](https://unity.com/download)
- **How-to Guide:** [Getting Started with Unity](https://learn.unity.com/)

### 3. **Unreal Engine**
- **Purpose:** Advanced game engine for developing high-quality 3D games.
- **Download Link:** [Download Unreal Engine](https://www.unrealengine.com/en-US/download)
- **How-to Guide:** [Getting Started with Unreal Engine](https://www.unrealengine.com/en-US/onlinelearning-courses)

### 4. **XAMPP**
- **Purpose:** Local web server environment for website development.
- **Download Link:** [Download XAMPP](https://www.apachefriends.org/download.html)
- **How-to Guide:** [How to Install and Use XAMPP](https://www.apachefriends.org/faq.html)

### 5. **Bitvise SSH Client**
- **Purpose:** SFTP and SSH client for secure file transfers and remote access.
- **Download Link:** [Download Bitvise SSH Client](https://www.bitvise.com/ssh-client-download)
- **How-to Guide:** [Bitvise Client Setup Guide](https://www.bitvise.com/ssh-client-documentation)

## 🔒 Security and Best Practices
- Ensure all tools are updated to their latest versions.
- Use strong, unique passwords for each account and enable two-factor authentication (2FA) where applicable.
- For any issues, refer to the respective tool's documentation or contact the Team Lead.
