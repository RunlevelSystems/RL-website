How to track participation fairly — short plan + a concrete allocation method
Yes — you can (and should) use GitHub activity as one input to determine each contributor’s share of the contributors’ 50% pool, but don’t rely on it alone. GitHub is excellent for coding work, PRs, and issue activity, but it misses customer support, server ops, game testing, design work, mentoring, and hours spent debugging infra. The most fair systems combine automated GitHub metrics + logged hours + non-code task tracking + a lightweight human review.

Below is a practical, implementable approach you can start with immediately.

1) Multi-source scoring (recommended inputs)
Collect a score for each contributor each quarter from these components:

GitHub activity (code & issue work) — PRs merged, issues closed, review activity, test coverage contributions. (Suggested weight: 25%)

Hours logged (time tracking) — manual or via Toggl/Clockify. (Suggested weight: 30%)

Operational / support work — support tickets closed, server maintenance tasks, uptime restores, backups. (Suggested weight: 20%)

Game testing / QA / content (non-code) — bug reports verified, test sessions, mod art/assets. (Suggested weight: 15%)

Impact / leadership / special contributions — product ideas enacted, release leads, mentoring. (Suggested weight: 10%)

Weights must sum to 100%. You can tune them — these weights prioritize time + ops while still valuing GitHub code activity.

2) Using GitHub as a data source
What to pull from GitHub:

PRs opened, PRs merged, lines changed (but careful — LOC is a poor quality metric), review comments made, issues opened/closed, labels indicating “customer bug” or “feature”, and release tagging.

Use the GitHub API to gather metrics programmatically (GitHub Actions can run a quarterly job to collect data).

Tools to consider (or replicate via API): simple scripts using gh CLI or direct REST API calls. (I can provide a starter GitHub Action or script.)

Important caveats:

Commits by bots or automated formatting should be filtered.

One-liner fixes shouldn’t count the same as multi-day architecture work. Use a tie-breaker: PR size + review count + time spent logged.

3) Concrete scoring & payout formula (example)
Workflow each quarter:

Gather raw metrics per contributor for each component.

Normalize each component to a 0–100 score (so different metrics are comparable).

Apply weights to produce a final score for each contributor.

Distribute the contributors’ pool (50% of net profits) pro rata by final score.

Example with numbers
Assume net profit this quarter = $10,000.
Founder keeps 50% = $5,000. Contributors pool = $5,000.

Three contributors: Alice, Bob, Carlos.

After data & normalization we get component scores:

Alice: GitHub 80, Hours 100, Ops 70, QA 50, Impact 60

Bob: GitHub 60, Hours 80, Ops 90, QA 80, Impact 40

Carlos:GitHub 90, Hours 60, Ops 40, QA 70, Impact 80

Apply weights (GitHub 25%, Hours 30%, Ops 20%, QA 15%, Impact 10%) to compute weighted score:

Compute Alice step-by-step:

GitHub: 80 * 0.25 = 20.00

Hours: 100 * 0.30 = 30.00

Ops: 70 * 0.20 = 14.00

QA: 50 * 0.15 = 7.50

Impact: 60 * 0.10 = 6.00

Alice total = 20 + 30 + 14 + 7.5 + 6 = 77.5

Bob:

GitHub: 60 * 0.25 = 15.00

Hours: 80 * 0.30 = 24.00

Ops: 90 * 0.20 = 18.00

QA: 80 * 0.15 = 12.00

Impact: 40 * 0.10 = 4.00

Bob total = 15 + 24 + 18 + 12 + 4 = 73.0

Carlos:

GitHub: 90 * 0.25 = 22.50

Hours: 60 * 0.30 = 18.00

Ops: 40 * 0.20 = 8.00

QA: 70 * 0.15 = 10.50

Impact: 80 * 0.10 = 8.00

Carlos total = 22.5 + 18 + 8 + 10.5 + 8 = 67.0

Total contributor score sum = 77.5 + 73.0 + 67.0 = 217.5

Each person’s share of the contributors pool ($5,000):

Alice: 77.5 / 217.5 = 0.3563 → $1,781.61

1) GitHub Action (quarterly metrics)
Create .github/workflows/quarterly_contributor_metrics.yml in any repo where you want the results to be stored (e.g., a private “ops” repo). This workflow:

Computes the last quarter (unless you override dates)

Pulls PRs merged, issues closed (non-PR), and PR reviews per contributor across all repos in an org or a given repo list

Writes metrics/metrics.json, metrics/metrics.csv, and a human-readable metrics/REPORT.md

Commits results to the repo

For org-wide visibility, add a PAT secret named ORG_PAT (scopes: repo, read:org).
If you only need a single repo, the default GITHUB_TOKEN is fine.

name: Quarterly Contributor Metrics

on:
  schedule:
    # Run on the first day of each quarter at 01:10 UTC
    - cron: "10 1 1 1,4,7,10 *"
  workflow_dispatch:
    inputs:

          #!/usr/bin/env python3
          import os, sys, csv, json, time, math
          from datetime import datetime, timedelta, timezone
          from dateutil.relativedelta import relativedelta
          import requests

          GH_API = "https://api.github.com"

          def iso(dt): return dt.strftime("%Y-%m-%dT%H:%M:%SZ")

          def last_quarter_range(today=None):
            if not today: today = datetime.now(timezone.utc)
            q = (today.month - 1) // 3  # 0..3
            # start of current quarter
            start_cur_q = datetime(today.year, q*3 + 1, 1, tzinfo=timezone.utc)
            # end of current quarter
            end_cur_q = (start_cur_q + relativedelta(months=3)) - timedelta(seconds=1)
            # last quarter
            start_last_q = start_cur_q - relativedelta(months=3)
            end_last_q = start_cur_q - timedelta(seconds=1)
            return start_last_q, end_last_q

          def gh_headers(token):
            return {
              "Authorization": f"token {token}",
              "Accept": "application/vnd.github+json",
              "X-GitHub-Api-Version": "2022-11-28",
            }

          def paged_get(url, headers, params=None):
            params = params or {}
            items = []
            page = 1
            while True:
              p = params.copy()
              p.update({"per_page": 100, "page": page})
              r = requests.get(url, headers=headers, params=p)
              if r.status_code != 200:
                raise RuntimeError(f"GET {url} -> {r.status_code} {r.text}")
              batch = r.json()
              if not batch: break
              items.extend(batch)
              page += 1
              # Gentle rate-limiting
              time.sleep(0.2)
            return items

          def list_org_repos(org, headers):
            return paged_get(f"{GH_API}/orgs/{org}/repos", headers, params={"type":"all"})

          def list_repo_prs(owner, repo, headers, start_iso, end_iso):
            # Only merged PRs within range
            prs = paged_get(f"{GH_API}/repos/{owner}/{repo}/pulls",
                            headers, params={"state":"closed", "sort":"updated", "direction":"desc"})
            result = []
            for pr in prs:
              merged_at = pr.get("merged_at")
              if merged_at:
                if start_iso <= merged_at <= end_iso:
                  result.append(pr)
            return result

          def list_repo_issues_closed(owner, repo, headers, start_iso, end_iso):
            issues = paged_get(f"{GH_API}/repos/{owner}/{repo}/issues",
                               headers, params={"state":"closed", "since":start_iso})
            result = []
            for it in issues:
              if "pull_request" in it:  # skip PRs
                continue
              closed_at = it.get("closed_at")
              if closed_at and start_iso <= closed_at <= end_iso:
                result.append(it)
            return result

          def list_pr_reviews(owner, repo, pr_number, headers):
            return paged_get(f"{GH_API}/repos/{owner}/{repo}/pulls/{pr_number}/reviews", headers)

          def normalize(scores_dict):
            # min-max to 0..100 per metric key across users
            # input: {user: {"prs":X,"issues":Y,"reviews":Z}}
            # output: {user: {"prs_n":..,"issues_n":..,"reviews_n":..}}
            keys = ["prs", "issues", "reviews"]
            mins = {k: math.inf for k in keys}
            maxs = {k: -math.inf for k in keys}
            for u, m in scores_dict.items():
              for k in keys:
                v = m.get(k, 0)
                mins[k] = min(mins[k], v)
                maxs[k] = max(maxs[k], v)
            out = {}
            for u, m in scores_dict.items():
              out[u] = {}
              for k in keys:
                v = m.get(k, 0)
                if maxs[k] == mins[k]:
                  out[u][k + "_n"] = 100.0 if v>0 else 0.0
                else:
                  out[u][k + "_n"] = (v - mins[k]) * 100.0 / (maxs[k] - mins[k])
            return out

          def main():
            token = os.environ.get("ORG_PAT") or os.environ.get("GITHUB_TOKEN")
            if not token:
              print("ERROR: missing GITHUB_TOKEN/ORG_PAT", file=sys.stderr)
              sys.exit(1)
            headers = gh_headers(token)

            org = os.environ.get("INPUT_ORG") or os.environ.get("ORG")
            repos_csv = os.environ.get("INPUT_REPOS_CSV") or os.environ.get("REPOS_CSV")

            start_date = os.environ.get("INPUT_START_DATE") or os.environ.get("START_DATE")
            end_date   = os.environ.get("INPUT_END_DATE")   or os.environ.get("END_DATE")

            if start_date and end_date:
              start = datetime.fromisoformat(start_date).replace(tzinfo=timezone.utc)
              end = datetime.fromisoformat(end_date).replace(tzinfo=timezone.utc)
            else:
              start, end = last_quarter_range()

            start_iso_s = iso(start); end_iso_s = iso(end)

            repos = []
            if repos_csv:
              for r in [x.strip() for x in repos_csv.split(",") if x.strip()]:
                if "/" not in r:
                  print(f"Skipping malformed repo '{r}' (expected owner/name)", file=sys.stderr)
                  continue
                o, n = r.split("/", 1)
                repos.append({"owner": o, "name": n})
            elif org:
              for r in list_org_repos(org, headers):
                repos.append({"owner": r["owner"]["login"], "name": r["name"]})
            else:
              # Default to the current repo
              owner = os.environ.get("GITHUB_REPOSITORY_OWNER")
              name = os.environ.get("GITHUB_REPOSITORY","/").split("/",1)[-1]
              repos.append({"owner": owner, "name": name})

            # Aggregate raw metrics
            metrics = {}  # user -> dict
            def bump(user, key, inc=1):
              if not user: return
              d = metrics.setdefault(user, {"prs":0,"issues":0,"reviews":0})
              d[key] = d.get(key, 0) + inc

            for r in repos:
              owner, name = r["owner"], r["name"]
              # PRs merged
              prs = list_repo_prs(owner, name, headers, start_iso_s, end_iso_s)
              for pr in prs:
                author = (pr.get("user") or {}).get("login")
                bump(author, "prs", 1)
                # reviews per reviewer
                reviews = list_pr_reviews(owner, name, pr["number"], headers)
                for rw in reviews:
                  reviewer = (rw.get("user") or {}).get("login")
                  if reviewer:
                    bump(reviewer, "reviews", 1)
              # Issues closed
              issues = list_repo_issues_closed(owner, name, headers, start_iso_s, end_iso_s)
              for it in issues:
                closer = (it.get("closed_by") or {}).get("login") or ((it.get("user") or {}).get("login"))
                bump(closer, "issues", 1)

            # Normalize and weighted score (GitHub component only for now)
            norm = normalize(metrics)
            weights = {"prs_n": 0.5, "issues_n": 0.2, "reviews_n": 0.3}  # tune as desired
            rows = []
            for user, raw in metrics.items():
              n = norm.get(user, {"prs_n":0,"issues_n":0,"reviews_n":0})
              score = n["prs_n"]*weights["prs_n"] + n["issues_n"]*weights["issues_n"] + n["reviews_n"]*weights["reviews_n"]
              rows.append({
                "user": user,
                "prs_merged": raw.get("prs",0),
                "issues_closed": raw.get("issues",0),
                "reviews": raw.get("reviews",0),
                "prs_norm": round(n["prs_n"],2),
                "issues_norm": round(n["issues_n"],2),
                "reviews_norm": round(n["reviews_n"],2),
                "weighted_score": round(score,2)
              })

            rows.sort(key=lambda r: r["weighted_score"], reverse=True)

            os.makedirs("metrics", exist_ok=True)
            # JSON
            with open("metrics/metrics.json","w",encoding="utf-8") as f:
              json.dump({
                "range":{"start":start_iso_s,"end":end_iso_s},
                "repos":[f'{r["owner"]}/{r["name"]}' for r in repos],
                "weights":{"prs":0.5,"issues":0.2,"reviews":0.3},
                "data": rows
              }, f, indent=2)

            # CSV
            with open("metrics/metrics.csv","w",newline="",encoding="utf-8") as f:
              w = csv.writer(f)
              w.writerow(["user","prs_merged","issues_closed","reviews","prs_norm","issues_norm","reviews_norm","weighted_score"])
              for r in rows:
                w.writerow([r["user"], r["prs_merged"], r["issues_closed"], r["reviews"], r["prs_norm"], r["issues_norm"], r["reviews_norm"], r["weighted_score"]])

            # Markdown report (simple)
            with open("metrics/REPORT.md","w",encoding="utf-8") as f:
              f.write(f"# Quarterly GitHub Metrics\n\n")
              f.write(f"**Range:** {start_iso_s} → {end_iso_s}\n\n")
              f.write("**Weights:** PRs 50%, Issues 20%, Reviews 30%\n\n")
              f.write("| User | PRs Merged | Issues Closed | Reviews | Weighted Score |\n")
              f.write("|---|---:|---:|---:|---:|\n")
              for r in rows:
                f.write(f'| {r["user"]} | {r["prs_merged"]} | {r["issues_closed"]} | {r["reviews"]} | {r["weighted_score"]} |\n')

          if __name__ == "__main__":
            main()
